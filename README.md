## SpineH2IRL

### Overview 
The SpineH2IRL model was developed by [Energy Reform](https://energyreform.ie) as part of an SEAI RD&D Project which aimed to investigate the role of hydrogen in the future energy system. This served as a showcase to demonstrate the utility of various SpineOpt features including blended representative periods, multi-stage optimisation and distributed monte-carlo. This model is the pathway model utilising blended representative periods.

There are two versions of the model - a SpineOpt V1.1 version (latest) and V0.x (legacy).
